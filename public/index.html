Xget

High-performance acceleration engine for developer resources built on Cloudflare Pages.

Usage

Access resources by prefixing the path with the platform code:

https://your-domain.pages.dev/gh/user/repo/file.txt
GitHub repository file
https://your-domain.pages.dev/npm/package-name
npm package
https://your-domain.pages.dev/cr-docker/library/nginx
Docker Hub container
